# Тетрадь абитуриента — этап 1

## Цель проекта
«Тетрадь абитуриента» помогает школьнику спокойно начать путь к поступлению: пройти короткий онбординг, получить персональный чек-лист и двигаться по шагам без перегруза.

## Что реализовано на этапе 1
- многошаговый онбординг (5 шагов);
- валидация и сообщения об ошибках;
- сохранение ответов и задач в браузере;
- персональный чек-лист по выбранной стратегии;
- управление задачами (выполнить, отменить, добавить, изменить, удалить);
- фильтры задач и прогресс;
- состояние главной страницы на основе данных пользователя;
- адаптация под мобильные экраны.

## Быстрый запуск
### Frontend
```bash
pnpm -C frontend install
pnpm -C frontend dev
```

### Проверка сборки
```bash
pnpm -C frontend build
```

### Backend (для текущего этапа не обязателен)
```bash
pnpm -C backend install
pnpm -C backend dev
```

## Структура проекта
- `frontend/` — интерфейс и вся логика этапа 1.
- `backend/` — базовый серверный шаблон (без продуктовой логики этапа 1).
- `docs/` — продуктовые и дизайн-материалы.

## Список страниц
- `/` — главная;
- `/onboarding` — онбординг;
- `/checklist` — персональный чек-лист;
- `/ege` — раздел ЕГЭ (демо);
- `/olympiads` — раздел олимпиад (демо);
- `/events` — мероприятия (демо);
- `/favorites` — избранное (демо-пустое состояние);
- `/pitfalls` — подводные камни;
- `*` — страница «не найдено».

## Где находится ключевая логика
- Онбординг: `frontend/src/pages/Onboarding.tsx`
- Чек-лист: `frontend/src/pages/Checklist.tsx`
- Главная (персональное состояние): `frontend/src/pages/Index.tsx`
- Хранение данных: `frontend/src/lib/applicant-data.ts`

## Как хранятся данные
Используется localStorage браузера:
- `applicant-notebook:onboarding:v1` — ответы онбординга;
- `applicant-notebook:checklist:v1` — задачи чек-листа.
