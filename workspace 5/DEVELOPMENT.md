# DEVELOPMENT

## Назначение
Этот документ описывает рабочий процесс разработки для этапа 1 проекта «Тетрадь абитуриента».

## Технологический контур этапа 1
- Клиентская часть: React + Vite.
- Серверная часть: шаблонный backend (на этапе 1 продуктово не используется).
- Хранение пользовательских данных: localStorage в браузере.

## Команды разработки
### Запуск фронтенда
```bash
pnpm -C frontend install
pnpm -C frontend dev
```

### Сборка фронтенда
```bash
pnpm -C frontend build
```

### Запуск бэкенда (опционально)
```bash
pnpm -C backend install
pnpm -C backend dev
```

## Ключевые модули
- `frontend/src/pages/Onboarding.tsx` — сценарий опроса и итоговое резюме.
- `frontend/src/pages/Checklist.tsx` — персональный чек-лист и операции с задачами.
- `frontend/src/pages/Index.tsx` — персональные блоки на главной странице.
- `frontend/src/lib/applicant-data.ts` — чтение/запись/очистка localStorage.

## Правила изменения этапа 1
1. Не добавлять крупные новые функции без отдельной задачи.
2. Не подключать серверные сценарии, авторизацию и внешние интеграции.
3. Перед завершением изменений всегда проверять:
   - открытие маршрутов;
   - сборку;
   - отсутствие ошибок рантайма;
   - сохранение данных после обновления страницы.

## Проверка перед передачей
- Проект должен собираться командой `pnpm -C frontend build`.
- Все базовые маршруты должны отвечать корректно.
- Документация (`README.md`, `PROJECT_STATE.md`, `TODO.md`, `CHANGELOG.md`) должна быть актуальна.
