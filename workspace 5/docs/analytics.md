# Будущая архитектура аналитики

> Документ описывает только будущую модель аналитики. В этапе 5 реализованы только базовые демонстрационные блоки.

## Цель
Давать пользователю понятную сводку по личному плану и подсказывать следующий шаг.

## Планируемые показатели
- количество задач;
- выполненные задачи;
- активные задачи;
- просроченные задачи;
- дедлайны;
- прогресс по категориям;
- рекомендации по следующим шагам.

## Будущая схема работы
1. Система собирает данные только из личного плана пользователя.
2. Считает показатели по простым правилам.
3. Показывает сводку в личном кабинете.
4. Формирует рекомендации на основе текущего состояния задач и сроков.

## Ограничения по данным (privacy by default)
Нельзя собирать без необходимости:
- историю посещений;
- клики;
- поведение пользователя;
- рекламные идентификаторы;
- данные других пользователей.

## Что не реализовано в этапе 5
- полноценная аналитическая система;
- расширенные отчеты и прогнозы;
- внешние аналитические сервисы;
- сбор поведенческих данных.
