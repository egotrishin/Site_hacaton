# Будущая архитектура Telegram-бота

> Документ описывает только будущую концепцию. В этапе 5 бот и интеграция Telegram не реализуются.

## Цель
Дать пользователю дополнительный канал напоминаний по личному плану поступления.

## Планируемые возможности
- напоминания о дедлайнах;
- задачи на сегодня;
- просроченные задачи;
- прогресс пользователя;
- подключение и отключение бота;
- настройки уведомлений.

## Будущий пользовательский сценарий
1. Пользователь в личном кабинете включает Telegram-канал.
2. Система подтверждает, что подключение выполняет владелец аккаунта.
3. Пользователь выбирает типы напоминаний и частоту.
4. Бот присылает только выбранные уведомления.

## Требования безопасности
- токен бота должен храниться только в защищенном хранилище;
- доступ к токену должен быть строго ограничен;
- обязательно проверять, что Telegram-аккаунт подключает владелец профиля;
- при отключении канала отправка сообщений должна полностью останавливаться.

## Что не реализовано в этапе 5
- сам бот;
- API;
- webhook;
- polling;
- фоновые задачи;
- реальные сообщения;
- рабочее подключение Telegram.
